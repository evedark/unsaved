# AI research workflow for turning videos into usable notes

**Central idea:** A long video becomes useful when the system extracts the thesis, the workflow, the examples, and the decision it changes. The output should be a note that can drive action, not a transcript archive.

## Breakdown
- Start with the problem the video solves.
- Separate the creator's thesis from the examples used to support it.
- Capture workflows as ordered steps, not paragraphs.
- Mark unsupported claims as claims, not facts.
- Connect the note to one current project or mark it as shelf-help.
- End with one next action so the saved content does not become another archive.

## Why this matters
This is the core promise of Unsaved: saved media should become applied knowledge, not a pile of future obligations.
