# Examples

These are public, sanitized examples that show the Unsaved output format.

They avoid private client names, budgets, credentials, internal vault paths, health details, and personal records.

Use them to understand the note shape:

1. `instagram-carousel-design-skills.md` - Instagram carousel style extraction.
2. `instagram-carousel-color-palettes.md` - Instagram carousel reference extraction.
3. `youtube-ai-research-workflow.md` - YouTube long-form breakdown.
