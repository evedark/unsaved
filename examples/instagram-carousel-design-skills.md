# Seven design skills for sharper product content

**Central idea:** Good product content is easier to understand when the visual system has hierarchy, spacing, contrast, rhythm, type discipline, color restraint, and one clear idea per frame.

## Breakdown
- **Hierarchy:** Make the main point obvious before the viewer reads details.
- **Spacing:** Use empty space as structure, not decoration.
- **Contrast:** Separate headline, proof, and supporting notes with size and weight.
- **Rhythm:** Repeat layout patterns so a carousel feels intentional.
- **Typography:** Use fewer type styles and make them do more work.
- **Color restraint:** Use one accent only when it carries meaning.
- **One idea per frame:** A slide should teach one thing, not hold every thought.

## Why this matters
This helps turn internal product decisions into public artifacts people can read quickly.
